### 1.3 Four-Tier Instrument Survival & Evaluation Standard
To prevent premature elimination of `1COIN` or `NCOIN` through overly narrow minimalist reductionism—while still enforcing our non-redundancy mandate—every currency instrument and candidate sub-model is evaluated across four distinct classification outcomes:

* **Tier S1 — Mechanically Indispensable:** Removing the instrument causes a direct state-machine failure, double-spend vulnerability, or loss of a required transactional invariant that `QC` plus a standard audit log cannot reproduce.
* **Tier S2 — Mechanically Reducible but Operationally Advantageous:** A single `QC` ledger could theoretically emulate the function, but retaining the distinct instrument provides superior separation of authority (e.g., separating the valuation oracle from the settlement treasury), atomic finality, non-repudiation, or cross-environment handoff clarity.
* **Tier S3 — Mechanically Redundant but Narratively / Worldbuilding Retained:** The instrument adds no distinct mechanical transition beyond a standard log, but is intentionally preserved by the Project Owner for diegetic clarity, dramatic stakes, or institutional roleplay within the OAL canon, with its mechanical redundancy transparently documented.
* **Tier S4 — Internally Inconsistent or Unnecessary (Rejected):** The candidate model contradicts protected distinctions, creates unresolvable circularity, or adds complexity with neither operational nor narrative benefit.

## PART III — Mathematical & Computational Analysis of `M04` Feedback (`P2.3`)

### 3.1 Formal Proof: Simultaneous Fixed-Point vs. Time-Lagged Dynamical Recurrence
Across the November 6 pilot recommendations, ChatGPT, Claude, Perplexity, and Gemini all highlighted Perplexity's `M04` endogenous feedback model as the premier mathematical test case for the laboratory. Here we unify the three mathematical analyses (ChatGPT's fixed-point admissibility check, Claude's negative-regime oscillation analysis at $\alpha = -0.5$, and Gemini's lagged closed-form sum) into one complete theorem and executable simulation check.

#### A. Model 1 — Simultaneous Static Resolution (`QC-S` / Unlagged `QC-R` in Year $t$)
Let exogenous baseline sector expenditure be $B > 0$ (e.g., $B = 100$ test-units). Let the QC allocation $I$ be defined simultaneously as twice total measured spending $G$, where a fraction $\alpha$ of $I$ is counted inside $G$ during the same evaluation frame:
$$I = 2G, \quad G = B + \alpha I \implies I(1 - 2\alpha) = 2B \implies I^* = \frac{2B}{1 - 2\alpha}$$

* **Regime 1 ($0 \le \alpha < 0.5$):** Unique, positive, finite equilibrium $I^* > 0$. (At $B=100, \alpha=0.25$, $I^* = 400$).
* **Regime 2 ($\alpha = 0.5$ — The Simultaneous Singularity):** $0 \cdot I = 200$. **No finite solution exists** (`INCOHERENT_TARGET / ALGEBRAIC_DIVERGENCE`).
* **Regime 3 ($\alpha > 0.5$ — Inadmissible Negative Fixed Point):** The algebraic fixed point $I^* = \frac{2B}{1 - 2\alpha} < 0$ is strictly negative (e.g., at $\alpha = 0.75$, $I^* = -400$). Under a non-negative allocation constraint ($I \ge 0$), no admissible equilibrium exists.

#### B. Model 2 — Time-Lagged Discrete Dynamical System (`QC-D` / Lagged `QC-R` Across Steps $t = 0, 1, \dots, T$)
Now suppose the QC valuation oracle observes total spending $G_t$ at period $t$, where $G_t = B + \alpha I_{t-1}$ (with initial seed $I_0 = 2B$ at $t=0$ when $I_{-1} = 0$), and sets $I_t = 2G_t$:
$$I_t = 2B + 2\alpha I_{t-1}$$
Unrolling this first-order linear non-homogeneous recurrence relation yields the exact closed-form trajectory for any finite horizon $t \ge 0$:
$$I_t = 2B \sum_{k=0}^{t} (2\alpha)^k = \begin{cases} \frac{2B}{1 - 2\alpha} \left(1 - (2\alpha)^{t+1}\right) & \text{if } \alpha \neq 0.5 \\ 2B(t + 1) & \text{if } \alpha = 0.5 \end{cases}$$
Furthermore, the perturbation error $e_t = I_t - I^*$ around the fixed point satisfies $e_{t} = (2\alpha)^t e_0$. This establishes four distinct dynamical regimes (verified numerically in **Table 4 of Part IV**):

1. **Monotonic Asymptotic Convergence ($0 \le \alpha < 0.5$):** Because $|2\alpha| < 1$, $(2\alpha)^{t+1} \to 0$ as $t \to \infty$, and $I_t$ converges smoothly to $I^* = \frac{2B}{1 - 2\alpha}$.
2. **Linear Arithmetic Growth Without Division-by-Zero ($\alpha = 0.5$):** In a lagged state machine, $\alpha = 0.5$ **does not crash at $t=0$**. Instead, $I_t = 2B(t + 1)$ grows linearly by $+2B$ per year. Over a bounded 150-year horizon ($t = 0..149$ with $B=100$), every annual payment is finite ($I_{149} = 30,000$) and the 150-year cumulative sum is exactly:
   $$\sum_{t=0}^{149} I_t = 200 \times \frac{150 \times 151}{2} = 2,265,000\text{ test-units}$$
3. **Geometric Runaway Divergence ($\alpha > 0.5$):** Because $2\alpha > 1$, $I_t > 0$ remains strictly positive at every step (never hitting the negative algebraic fixed point $I^* < 0$) but explodes exponentially as $(2\alpha)^{t+1}$.
4. **Negative / Counter-Cyclical Dampening vs. Neutral Oscillation ($\alpha < 0$):** If QC investment displaces or crowds out baseline spending ($\alpha < 0$), convergence holds for $-0.5 < \alpha < 0$ via damped alternating oscillations. At **$\alpha = -0.5$** (Claude's boundary case), $2\alpha = -1$: the fixed point $I^* = B = 100$ exists algebraically, but the recurrence $I_t = 200 - I_{t-1}$ oscillates perpetually between $200, 0, 200, 0, \dots$ and never settles!

#### C. Reproducible Python Simulation & Assertion Script (`M04-feedback-sim.py`)
To satisfy Perplexity's Level `E2` (Reproducible Executable Model) standard, the following self-contained Python script verifies all five regimes and outputs the exact values recorded in Table 4:

```python
def simulate_m04_feedback(B: float, alpha: float, steps: int = 150) -> dict:
    """E2 Executable Reference Model for OAL Currency Laboratory Case M04."""
    fixed_point = (2.0 * B) / (1.0 - 2.0 * alpha) if alpha != 0.5 else None
    trajectory = []
    I_prev = 0.0
    for t in range(steps):
        G_t = B + alpha * I_prev
        I_t = 2.0 * G_t
        # Closed-form verification check
        expected = (
            2.0 * B * (t + 1)
            if alpha == 0.5
            else (2.0 * B * (1.0 - (2.0 * alpha) ** (t + 1))) / (1.0 - 2.0 * alpha)
        )
        assert abs(I_t - expected) < 1e-6, f"Recurrence mismatch at t={t}"
        trajectory.append((t, round(G_t, 4), round(I_t, 4)))
        I_prev = I_t
    return {
        "B": B,
        "alpha": alpha,
        "fixed_point": fixed_point,
        "I_0": trajectory[0][2],
        "I_1": trajectory[1][2],
        "I_10": trajectory[10][2],
        "I_149": trajectory[-1][2],
        "cumulative_150yr": round(sum(x[2] for x in trajectory), 2),
    }
```
