# USAGE GUIDELINES

## How to Use This Template

1. **Copy the entire template** for each new power/skill/ability
2. **Fill in all applicable fields** - some may not apply to every entry
3. **Use [brackets] for placeholder text** that you haven't filled in yet
4. **Be as detailed as possible** in each section
5. **Update version numbers** each time you revise
6. **Cross-reference related documents** to build interconnected system
7. **Maintain consistent terminology** across all documentation

## Field Priority Levels

**Essential (must fill these):**
- Name
- Type
- Category
- Tier Level
- Core Logic System
- Abstract Principle
- Concrete Applications (at least 3)
- Mechanics
- Unique Limitation

**Important (should fill these):**
- Domain
- Scope Designation
- Operational Framework
- Activation Method
- Universal Constraints
- User Requirements

**Supplementary (fill as relevant):**
- All other fields based on complexity and importance

## Tips for Different Types

**For POWERS:**
- Emphasize innate nature and automatic function
- Focus on what it "does" rather than "how to do it"
- Highlight natural limitations

**For SKILLS:**
- Emphasize learning curve and mastery stages
- Detail training requirements
- Focus on technique and practice

**For ABILITIES:**
- Balance between innate and learned aspects
- Show progression possibilities
- Explain versatility
