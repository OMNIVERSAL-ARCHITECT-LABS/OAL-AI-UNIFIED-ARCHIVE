### Workstream 3 (WS3): The 3-Second Cycling Hypothesis & Split-Plane Architecture
**`[R] [C] [N]` Confidence: High | Evidence Grade: `[Grade A/D]`:**
* **Why Naive Full-Stack 3-Second Rotation Fails:** If the synthetic environment rotates its presentation-layer IP addresses, DNS A-records, TLS session keys, and SSH host banners every 3.0 seconds directly facing a latched attacker, three fatal failures occur: (1) active TCP streams and interactive shells drop or freeze every 3 seconds due to sequence-number and key-schedule invalidation; (2) BGP and DNS caches cannot propagate in 3 seconds (standard BGP route convergence requires 30–180 seconds; MTD surveys by MDPI (2023) and Security and Communication Networks (2022) highlight severe QoS degradation when mutation intervals approach round-trip latency); and (3) a deterministic 3.0-second metronome acts as an unmistakable cryptographic beacon that immediately tells any automated scanner it is inside an artificial construct.
* **The Engineering Solution — Split-Plane Asynchronous Virtualization:** To preserve the Architect's locked 3-second canon rule while making the mechanics technically sound, we separate the architecture into two planes:
  1. **The Underlay Control & Reconnaissance Plane (Rotates Every ~3.0 Seconds):** Unlatched external virtual IP mappings, container memory offsets, micro-segmented SDN paths, and ephemeral inter-node encryption keys rotate every 3 seconds. This prevents unlatched external scanners from mapping the topology and neutralizes memory-resident persistence or lateral breakouts.
  2. **The Overlay Presentation & Session Plane (Stateful Anchor Proxy):** Once an attacker "latches on" (commits to a session), an SDN/eBPF translation proxy (Fan et al., 2017; d'Ambrosio et al., 2025) pins their perceived TCP sequence state, TLS session ticket, and terminal view across underlay rotations. To the attacker, the session feels continuous—save for a subtle 4–12 millisecond clock-skew micro-jitter every 3 seconds as the underlying container migrates (providing the exact sensory clue needed for Beat 3 of the Attacker POV scene).
